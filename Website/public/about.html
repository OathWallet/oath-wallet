Is Oath right for me?

Oath is a self-custody wallet for iPhone and iPad running iOS or iPadOS 17 or later. It is free to download. You authorize transactions on your device and review network fees before sending. Android users need a different wallet. Check the official App Store listing.

I want a wallet without an account

You can create a wallet without providing an email, phone number or identity document. Keep a recovery copy you control. For eligible wallets, an encrypted iCloud restore requires both the backup file and its separate password. Electrum and aezeed wallets require their original recovery material. Read the backup requirements.

I already use Electrum for Bitcoin

Oath can restore supported Electrum seed formats. Identify the original account type and seed extension, then compare a known receiving address before using the restored wallet. The dated lab edition shows which receive and change addresses were checked using public fixtures. See the Electrum guide and review the compatibility results.

I want to receive USDT on TRON

Choose USDT on TRON in Oath and share your wallet’s TRON receiving address. Choose the matching TRON (TRC-20) network in the sending app. The token contract identifies the asset. Use the address on your own Receive screen as the destination. An outgoing transfer uses TRON resources and may require TRX. Check the token and fee details.

I want to connect a dApp or review an approval

Use WalletConnect to review the website, accounts and networks it requests. Check existing token permissions separately. On TRON, the removal flow covers supported token and collectible permissions. Account-control keys have a different scope. See supported connections and check approval limits by network.

I want to use my own language

The app offers 57 localization choices, including Arabic, English, Japanese, and Brazilian and European Portuguese. The choices include regional variants. See how to change language in Oath.

What Oath does

Oath is a self-custody wallet: you control the recovery credentials and authorize transactions on your device. It brings supported wallet imports, Bitcoin address choices, network-fee review, WalletConnect and optional encrypted iCloud backup into one app. Supported features depend on the network, wallet type and release.

Explore the features, check the supported networks, or start with the backup and recovery guide.

What a reviewed guide means

Capability claims are checked against the release named on the page. Where a guide documents compatibility, it explains the account formats checked, the evidence used and the limits of that check. Source review, host tests and a completed live transaction are separate kinds of evidence.

We use original app captures and label their capture version and sample data. Catalog entries come from a pinned discovery snapshot; inclusion is not issuer verification or a safety endorsement. We link to primary network and issuer information where it helps you verify an identity or requirement.

Updates and corrections

A page’s update date changes when its content changes, not every time the website deploys. Historical screenshots and release records keep their original scope. Read the release history for confirmed distribution and changes.

For a correction, send the page URL and the issue to care@oathwallet.org. Never include recovery words, private keys or backup passwords. Report vulnerabilities using the security reporting policy.

For reviewers and ecosystem directories

The press kit, network guides, feature scope and security evidence provide attributable product information. Link to the specific capability you describe and retain its release and network restrictions. A listing does not imply a partnership or security endorsement.

Help and vulnerability reports

For product guidance, use the support page and practical guides. For a security issue, follow the repository’s reporting policy. That policy describes the status of its private reporting channel; do not post exploit details in a public issue while arranging a private channel.

Never send a recovery phrase, private key, passphrase, backup credential or passkey to anyone claiming to be support. Oath cannot recover missing credentials or reverse an on-chain transaction.
