Trust Wallet, MetaMask and Electrum account conventions compared with Oath 5.0.2 (104). Source review, reference-library vectors and Oath core host tests; no installed third-party app or funded-transfer testing.

Accepted run completed 2026-11-09T20:43:42.773Z. Published by the Oath team; this is a first-party engineering reference, not an independent certification.

The Electrum fixture bundle contains 22 cases and 132 address expectations across 2fa, 2fa_segwit, old, segwit, standard. Those expectations run inside one host test; they are not 132 separate app tests. The bundle is pinned to Oath’s source and file hash. A single upstream Electrum app version was not established for the entire bundle.

Read or asserted against the pinned released source. This does not run an importer.

Public fixtures executed in Wallet Core 4.8.4 WASM, with Oath path declarations checked separately. This does not execute the Oath app importer.

Oath core host tests

Actual released OathBitcoin Swift code executed on a Mac, using public fixtures and mocked discovery where specified. This does not launch the iPhone app.

Limited checks; migration unverified

Some cryptographic fixtures pass, but the original account policy or full restoration workflow is not established.

Not evaluated

Later or separately imported EVM account

A different account needs its own key or matching path

Example later leaf: m/44'/60'/0'/0/1

Electrum-generated SegWit seed

Native SegWit derivation fixtures pass

Root m/0'; receive /0/i; change /1/i

Electrum · Oath core host tests

Old Electrum seed encoding

Old-format fixtures pass

Legacy Electrum derivation

The pinned fixture set includes old-format seed decoding and legacy address/key expectations, exercised by Oath core.

Limit: Old seeds do not support an extra seed extension in this implementation. An encrypted wallet-file password is not the same as a seed extension.

Electrum · Oath core host tests

Standard or SegWit seed with extension

Normalization and account isolation checks pass

Same seed format and exact extension

Oath core tests check extension normalization and distinct account results. Restoring the original wallet requires the same extension used to create it.

Limit: The website cannot recover a forgotten extension. Oath 5.0.2 excludes Electrum-derived wallets from its encrypted iCloud export; retain the original seed and extension backup privately.

Bitcoin: four address types checked in core code.

These tests execute OathBitcoin on macOS. They do not demonstrate an installed wallet migration or a funded spend. A Bitcoin address beginning with 3 or bc1 can represent other scripts outside this single-key scope.
