# Oath Wallet 5.1.2 (112)

Source release: [`v5.1.2-build112`](https://github.com/OathWallet/oath-wallet/releases/tag/v5.1.2-build112). Version alias: `v5.1.2`.

## Changes

- **Smarter recovery-phrase imports.** Paste numbered lists, bullets, punctuation, repeated spaces or blank lines. Valid phrases reach the importer in their original word order with the normal dictionary and checksum checks. The same cleanup is used for formatted QR input, with separate BIP39, Electrum and aezeed decoding.
- **Copy an address from Home.** Press and hold an asset to copy its verified receive address. A brief confirmation identifies the asset and network. Bitcoin-family, Solana and TON addresses keep their network-specific preparation and formatting.
- **Pending transaction counts.** History shows a count for the selected wallet and account scope. The count follows new transactions and confirmations, avoids duplicates and can be hidden in Preferences.
- **Smoother navigation.** Refined sidebar movement, toolbar balance-label transitions and passcode-keypad symbols.
- **Updated translations and documentation.** New confirmation and preference labels, README, package documentation and website references for version 5.1.2, build 112.

Existing account-management, balance-chart, browser, network and app-icon features remain available. Keychain, application container, backup and database migration identities remain compatible.
