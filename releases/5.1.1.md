# Oath Wallet 5.1.1 (111)

Source release: [`v5.1.1-build111`](https://github.com/OathWallet/oath-wallet/releases/tag/v5.1.1-build111). Version alias: `v5.1.1`.

## Changes

- Add, select, rename and remove EVM and Solana accounts, with custom derivation paths, scoped Home balances and transaction history, and encrypted backup recovery.
- Add native balance history charts, interactive scrubbing and haptic feedback.
- Update the browser with normal and private tabs, favorites, recent sites, tab previews, search-engine choices, website connection approvals and native EVM transaction review.
- Add Plasma, World Chain and Elysium, with network artwork, RPC routing and asset discovery.
- Refine Home navigation, toolbar balance presentation, asset visibility, wallet grouping, scrolling, refresh and backup reminders.
- Refresh welcome and unlock presentation, biometric prompting and app icon selection, including Vice Sunset.
- Improve import keyboard behavior, account key-export navigation, fee guidance, market-data recovery, TRON discovery and THORChain fallback handling.
- Update the README, package documentation and website release references to 5.1.1, build 111.

Existing Keychain, application container, backup and migration identities remain compatible. Capabilities depend on the wallet, network and provider.

## Build

```sh
git checkout --detach v5.1.1-build111
sh Tools/PreparePublicBuild.sh
xcodebuild -project OathAtmosphere.xcodeproj -scheme OathAtmosphere \
  -configuration Debug -destination 'generic/platform=iOS' \
  -derivedDataPath /tmp/oath-5.1.1-build111 CODE_SIGNING_ALLOWED=NO build
```

Version fields follow Apple's [release version](https://developer.apple.com/documentation/bundleresources/information-property-list/cfbundleshortversionstring) and [bundle build](https://developer.apple.com/documentation/bundleresources/information-property-list/cfbundleversion) definitions.
